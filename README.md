# Productivity-Dashboard
A modern and interactive Productivity Dashboard built using HTML, CSS, and JavaScript. This dashboard helps users manage their daily productivity with features like task management, daily planning, motivational quotes, a Pomodoro timer, weather updates, and multiple theme modes — all inside a clean, responsive UI.

Features:

✅ Todo Manager -
- Add tasks with details
- Mark important tasks
- Remove completed tasks
- Persistent storage using localStorage

📅 Daily Planner -
- Hourly planner for the entire day
- Auto-save functionality
- Persistent planner data using localStorage

💡 Motivational Quotes -
- Random quote generator using API
- Dynamic quote and author rendering

⏳ Pomodoro Timer -
- 25-minute work session
- 5-minute break session
- Start, Pause, and Reset controls

🌦️ Weather Widget -
- Real-time weather data
- Temperature, humidity, precipitation, and wind speed
- Live date and time display

🎨 Dynamic Themes -
- Multiple UI themes
- Smooth theme switching
